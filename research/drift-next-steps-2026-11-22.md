## 3. 已有上界给出的有限化接口

以下为直接纸面推论，未形式化，不声称新颖。旋转非轴完整漂移至 `v=(a,-b)`，`a,b>0`，令

```text
k = gcd(a,b)
eta = (b/k,a/k)
W = max_i eta dot p_i - min_i eta dot p_i
```

`W` 使用本原整数法向，不能与未经约分的 `b*x+a*y` 的跨度混淆。每一整数层在模完整漂移后恰有 `k` 个格子类，故奇数访问类的数量 `g` 满足 `g<=k*(W+1)`。

Ke 的双向指数时钟给出 `P^2<=A_+*A_-/kappa^2`。将最小层设为 0，选择指数底数 4，则

```text
kappa = 1 - 2/(4^eta_x+1) - 2/(4^eta_y+1) >= 1/5
0 < A_+ <= g*4^W
0 < A_- <= g
P <= 5*g*2^W <= 5*k*(W+1)*2^W
```

上界中的正性来自真实可实现性，估计上界时舍弃带符号和中的负项。固定非轴漂移和宽度因此足以有限化周期。对角情形有更强的粗界 `P<=g*(3^(W/2)-1)`。这些界可以很大，数学上的有限不等于现实中搜索可行。

[时钟、尾迹预算与非轴周期上界，原始证明 §7–10](https://github.com/kehao95/langtons-ant-core/blob/b3429c25c33519c14f58f0a7171a857092bbd4cc/wake_synthesis/PROOF.md)

因此缺口应写成：没有对所有本原周期轨道的漂移和宽度作统一控制；而不是没有任何周期上界工具。只锁定漂移 `(2,-2)` 仍不足以结束分类，因为宽度还可未知。

## 4. 本次候选：双记录前沿的时序兼容性

### 精确分岔

若 `a^2 != b^2`，则 `a+b`、`a-b` 都非零。定义

```text
F_plus(x,y)  = sign(a+b)*(x+y)
F_minus(x,y) = sign(a-b)*(x-y)
```

两者的周期增量分别为 `|a+b|`、`|a-b|`，均严格为正；它们的系数都是正负一，因此已有记录对的局部引理适用于两套前沿。轴向非零漂移也包含在该情形。

标准对角漂移恰在分岔另一侧：一个增量为零，只有一套增长的记录前沿。这提供一个可能区分对角与非对角的结构接口。

### 所求不是另一条计数下界

只对两套记录对分别计数，得到的仍是下界；取二者最大值只恢复 `4*(|a|+|b|)<=P`。未经证明也不能把两组记录区间当作不相交集合直接相加。

应保留每个 `100001` gadget 的精确位置相等、首次回返以及黑读的历史来源。尝试在两类 gadget 相互穿插时提取稳定访问秩约束，证明出现与全局时序不相容的循环，而非只对转向数求和。

可以研究的中间对象：按完整漂移取商，各事件记录所在类、纵向提升量和稳定时间 `tau_i=i-P*ell_i`；同一物理格上的首次回返必须连接相邻稳定秩。对固定有向格边，源和目的出现按顺序匹配，不可任意置换。寻找两套前沿强制出的差分约束正环，要求矛盾对所有正 `P` 成立。

这些时序工具已在 Ke 的单位对角排除中有效；将它们应用到双记录前沿是本次提出的研究方向，尚无证明，也未得到反例。不主张它比原分类问题容易，不能把候选描述写成定理。

### 第二阶段：对角倍数

即使证明 `a^2=b^2`，还剩完整漂移 `(m,-m)`。单位情形已排除，但不能据此推出 `m=2`。研究必须保留一层中的 `m` 个纵向余数类；单位证明中的两步 E,S 位移只在 `m=1` 时属于一个完整平移类，推广时这一关键推理失效。

若要得到 `m=2`，命题必须针对最小正周期。任意周期版本立即被标准字的重复否定。周期最小性、本原方向、完整位移中的最大公约数是三个不同概念。

## 5. 对势函数路线的限定

排除某组图统计量的仿射单调组合，不排除带空间权重和头部修正项的时钟，也不排除记录时刻返回映射上的势函数。Ke 的指数时钟就是后一类之外仍有工具的例子。周期时头部及未变遗迹的贡献抵消，得尾迹预算；任意轨道时没有这种抵消，不能由时钟增长直接推断弹道性。

因此第一开放块仍无本次可提交的引理。不建议把“改用复杂势函数”本身当作进展；必须给出完整状态量、单步或宏步不等式，以及它为何能控制回退或长期记忆。

## 6. 下一轮 propose -> refute -> verify 合同

建议先更新来源基线，然后只开两个窄任务，而非泛泛要求证明完整漂移为 `(2,-2)`：

1. 双记录前沿能否给出非对角漂移的时序障碍，优先包括带非空尾迹的轴向情况。
2. 单位对角的稳定秩证明在多纵向余数类中还能保留哪些恒等式，明确哪些结论必须加最小周期假设。

每个候选提交精确量词、适用假设、与已知结果的区别、关键证明步骤及一个适合 Lean 的最小引理。对抗者至少用标准字的任意幂和旋转、跨周期的提升量、合法首次回返的相邻秩、现存局部振荡子，以及仅满足 incidence 条件但不可实现的伪轨迹测试它。

接受的成果应为完整证明，或带全部自洽条件的明确反例，或准确定位推广失败的一条推理。单纯增加周期下界、重复已知 `g>=8`、把局部无解当全局分类，均不计为完成目标。

本轮未启动新的 Sonnet 流程，未查询或修改 Kaggle、远端 CaDiCaL 作业。运行时长不是完成证据；其结果应分别记录分片覆盖、退出状态、输入哈希及证书校验边界。
