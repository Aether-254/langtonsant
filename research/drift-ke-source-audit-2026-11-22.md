## 1. 单位对角漂移确实被全称排除

`unit-diagonal.tex` 的定理 `ud:thm:unit` 排除完整周期位移 `(1,-1)` 及其四分之一转旋转。假设是经典 RL 规则、有限初始黑集、非空无限重复转向字、周期末恢复朝向。没有周期、宽度、增长、种子大小的额外上界，也不要求周期最小；允许未读有限遗迹和有限暂态。

这里是 **full displacement**，不是本原方向：标准公路的 full drift 为 `(2,-2)`，其方向约分为 `(1,-1)`，不被排除。

[论文源码：unit-diagonal.tex，第 1–32 行](https://github.com/kehao95/langtons-ant-core/blob/b3429c25c33519c14f58f0a7171a857092bbd4cc/wake_synthesis/paper/unit-diagonal.tex#L1-L32)

证明利用单位对角漂移下每个横向层恰有一个完整平移类。按稳定访问时间 `tau_i = i - P*a_i` 排序，各类的转向从 R 开始交替。极值层为单次 R；向内两层的端口字被迫确定，第三层出现二元交错矛盾。关键并非仅有“读色交替”，而是**连续路径首次回到同一物理格，稳定访问秩必须恰好加一**；跨过若干奇数秩也不合法。

具体终局为 `p_2=q_1+1`、`p_4=q_3+1`，同时必须有 `p_1≠q_1`、`p_4≠q_4`。奇数层端口关系令每个偶数秩恰属一张列表、每个奇数秩同属两表或皆不属；这些条件不相容。本文阅读未发现该短交错论证的错误。作者保留的程序是回归检查，不是这条解析证明的前提。

[独立证明说明，第 20–179 行](https://github.com/kehao95/langtons-ant-core/blob/b3429c25c33519c14f58f0a7171a857092bbd4cc/wake_synthesis/verification/unit_diagonal_analytic/PROOF.md#L20-L179)

**不能原样推广至 `(m,-m)` 的原因（本次分析）。** 当 `m>1`，一层有 `m` 个纵向余数类，极端层不再提供单一的总端口边界 `I=J=1`。更具体地，首层论证中的两步 E,S 路径位移是 `(1,-1)`：在单位漂移时它连接同一完整平移类，稳定时间差为 `2-P`；在 `m>1` 时它跨余数类，不能在同一秩列表中得出该矛盾。标准 `(2,-2)` 轨迹也说明不能忽略这一区别。

`periodic-growth-closure.md` 已明确给出全称增长结论 `g>=8`。其依赖链是 `g∈4Z`、正增长和 `g>=2 max(|a|,|b|)`，把 `g=4` 缩至单位对角、两格轴向、两格对角三类，再分别使用单位对角排除与归属于 Jillhewar 的另两类排除。这是已有结论，不能作为本次新发现。该文另有两格轴向的 `P≡4 (mod 8)`、`8|g`，以及两格对角尾迹必须同时含两种棋盘奇偶类的全增长结论。

## 2. 轴向漂移已有带尾迹的必要条件

`axis:thm:main` 对任意完整轴向位移 `(a,0)`（旋转归一化至 `a>0`）证明 `a` 偶且

```text
I(O) = #{(u,v) in O^2 : x_u < x_v and y_u > y_v} = 0 mod 2
```

`O` 是一个周期中被奇数次访问的完整平移类，在 `0<=x<a` 中取代表。相同行或列不计严格逆序。没有零尾迹假设；高度、周期、增长均可任意。这个条件仍只是筛选：例如 `(a,0)=(4,0)` 时，四列在两条指定偶数行上的八个端点可通过旧余数约束及新逆序条件，作者不据此宣称存在真实轨道。

主要恒等式：实际奇偶边图 `G=G0(O) xor sum h_y R_y`，接缝绕数给出 `sum h_y=1 mod 2`；端口二次型满足 `q(G)=1`，完整水平行环的极化为零且加入行环使 `q` 翻转；最后 `q(G0)=I(O)+g/2`。结合 `4|g` 得到逆序条件。对 `a=2`，其结果简化为 `8|g`，并未排除所有轴向漂移。

## 3. “完全没有上界工具”需要修正

作者的通用 inverse-synthesis 论证已给出显式尾迹相关的周期上界。对于完整非轴漂移 `d=(a,-b)`、`a,b>0`，令 `k=gcd(a,b)`、`eta=(b/k,a/k)`，取 `r>1` 使

```text
kappa = 1 - 2/(r^eta_x + 1) - 2/(r^eta_y + 1) > 0
A_+ = -sigma * sum_(q in O) (-1)^(q_x+q_y) * r^(eta dot q)
A_- = -sigma * sum_(q in O) (-1)^(q_x+q_y) * r^(-eta dot q)
P^2 <= A_+ * A_- / kappa^2
```

两侧指数时钟的每步正增量在完整周期中求和，再用 Cauchy–Schwarz 得到此界。`O` 必须是显式给出的完整尾迹；这没有解决如何限制未知尾迹的大小或范围，也不包含轴向情况。对角漂移另有 `P <= g*(3^(W/2)-1)`，其中 `W` 是 `x+y` 的偶数跨度。

[证明说明 §8–10](https://github.com/kehao95/langtons-ant-core/blob/b3429c25c33519c14f58f0a7171a857092bbd4cc/wake_synthesis/PROOF.md#L412-L480)

### 从上述界直接推出的固定宽度推论

以下为本次纸面推导，非已完成的 Lean 定理，也不声称新颖。用本原法向定义 `W=max(eta dot p)-min(eta dot p)`。每个整数层在模完整位移 `d` 后有 `k` 个类，故 `g<=k*(W+1)`。

平移最低层至零，选 `r=4`，有 `kappa>=1/5`、`A_+<=g*4^W`、`A_-<=g`，因而

```text
P <= 5*g*2^W <= 5*k*(W+1)*2^W
```

因此固定非轴完整漂移和横向宽度，已经可以在数学上有限化周期搜索。局部振荡子破坏朴素的单列无环论证，但不反驳这条依赖全局稳定访问次序的上界。真正缺口仍是独立于未知轨道的漂移／宽度／尾迹约束；上述有限上界可能非常巨大。

## 4. 对下一轮任务的建议

- 把单位对角排除的桥接对象定义为稳定访问秩、同边按序匹配、首次物理回返秩相邻，避免仅重做长度枚举。
- 对轴向候选加入严格逆序筛选，并让对抗方主动构造满足筛选而尚未可实现的尾迹，防止把必要条件误当分类。
- 若探索漂移被迫为 `(±2,±2)`，必须明确采用最小正周期的 full drift；不能把本原方向与 full drift 混用。
- 条件性周期上界已经存在，下一轮应寻找控制尾迹或宽度的机制，或推广稳定秩阻碍，而非重新声称所有可用工具均为下界。
