# T4：有限初态最终周期性的密度弱化与缓存失配接口

日期：2026-11-22。范围：第二轮 brainstorm 的 T4。本文为正式研究笔记；没有新增 Lean 定理，没有解决任意有限支撑初态的最终周期性。

## 0. 交付结论及“严格较弱”的精确含义

本次主要交付属于任务书的 **(3) 精确定位失败步骤**，同时给出两个完整的纸面桥接证明和一个满足真实蚂蚁动力学的分离例子。

建议中间目标是：**存在固定正整数滞后，使读色序列的不匹配时刻具有自然密度零**，下文记为 `DensityPeriodicReads`。它不要求最终全部匹配，不指定 104，不要求统一漂移或平均速度存在。建议首先研究一个可观测的充分条件：**某个固定时间窗口之外发生的黑读，其频率趋于零**，下文记为 `SparseCacheMisses`。

已完成的纸面结论是：

1. 任意真实轨道的 `SparseCacheMisses` 推出 `DensityPeriodicReads`，无需有限支撑，并给出显式计数界及周期选择。
2. 有限支撑的 `PeriodicTail` 推出以上两项；但“缓存失配最终不再发生”在有限支撑下又等价于 `PeriodicTail`，不能当作弱化。
3. 仓库已有的真实无限初态 `growingObstacles` 满足以上两项，却不满足 `PeriodicTail`。其中“不最终周期”和初态描述来自已有 Lean 定理；密度结论及下面的统一弹道估计是本次纸面推导，未编译验证。

**必须区分两种逻辑域。** 作为全体真实蚂蚁轨道上的谓词，`DensityPeriodicReads` 严格弱于 `PeriodicTail`：正向蕴含对任意棋盘成立，反向由上述真实无限初态否定。作为“任意有限支撑轨道”的全称猜想，本次只证明正向蕴含，**没有证明反向不成立**。若给出有限支撑状态 `s`，使弱性质成立而 `PeriodicTail s` 不成立，就已经反驳了第一开放块。不能在本任务中把这一未知事实写成已经证明的“有限支撑域内严格分离”。若将任务书的“严格弱于”要求解释为必须具有这样的有限支撑见证，本次未满足该额外要求；这是结果的实质边界，而不是术语调整。

## 1. 已有接口和不能重新包装的目标

设 `p_n = (run s n).pos`，`d_n = (run s n).dir`，`c_n = readColor s n`，`true` 表示黑读、左转。已有定义和证明为：

- [BallisticGeneral.lean:25](/D:/langtonsant/BallisticGeneral.lean:25)：`PeriodicTail s` 是存在 `T,P,v`，`P>0`，使所有 `n>=T` 有 `p_(n+P)=p_n+v` 且 `d_(n+P)=d_n`。
- [BallisticGeneral.lean:147](/D:/langtonsant/BallisticGeneral.lean:147)：有限支撑下，`PeriodicTail`、`Ballistic`、`EventuallyBoundedMemory` 等价。
- [BoundedMemory.lean:6](/D:/langtonsant/BoundedMemory.lean:6)：强有界记忆要求每次晚期读取，或者在最近 `W` 步有同格访问，或者是对初始白格的首次访问。
- [BoundedMemory.lean:41](/D:/langtonsant/BoundedMemory.lean:41)、[175](/D:/langtonsant/BoundedMemory.lean:175)：窗口键的有限性与条件性确定转移；不能只用窗口重复而删除决定读色的前提。
- [Ballistic.lean:8](/D:/langtonsant/Ballistic.lean:8)：弹道不等式对所有晚期时间区间成立，包含正速率和统一回退常数，不只是从固定原点测得的线性距离下界。

因此下列目标不计为新中间进展：证明最终统一回访间隔；证明强有界记忆；证明统一速率加回退界；把完整标准入口证书的最终可达性换名。已有调查还指出暂态性本身仍开放，且未提供连接到本任务的有效接口；本文不把“每格只访问有限次”重新列为成果。

## 2. propose：两个精确、可统计的命题

### 2.1 密度周期性：主要中间目标

定义有限计数

```text
D_s(P,N) = #{ n in Nat : n < N and c_(n+P) != c_n }.

DensityPeriodicReads(s) :=
  exists P in Nat, P > 0 and
    forall k in Nat, k > 0 ->
      exists N0 in Nat, forall N >= N0, k * D_s(P,N) <= N.
```

使用整数计数是为了不依赖 Mathlib 的实数极限或测度。量词次序是 `exists P, forall k, exists N0, forall N`；不允许周期随精度 `k` 或观测终点 `N` 改变。

**候选 C-D（未证明）：**

```text
forall s : State,
  FiniteSupport s.board -> DensityPeriodicReads(s).
```

`PeriodicTail s` 蕴含 C-D 对该状态的结论：取原正周期 `P`，已有 `HighwayFrom.reads_periodic` 使 `D_s(P,N)<=T`。取 `N0=k*T` 即可。这个方向不需要有限支撑。

该结论允许无穷多个异常，甚至允许在不同相位、不同局部周期之间切换。因此它没有宣称存在一个固定周期字与整条序列只有零密度的逐位差异，也没有宣称位置有固定密度漂移。后一类更强结论需要另证。

**非平凡性。** 这不是任意二进制序列的恒真性质。令 `b` 依次拼接长度为 `j` 的全部二进制字，`j=1,2,...`，每一层使用任意固定枚举次序。对固定 `P` 和 `j>P`，仅第 `j` 层各字内部就有 `(j-P)*2^(j-1)` 个滞后 `P` 的失配。到这一层结束的总长度是 `(j-1)*2^(j+1)+2`，故失配比例沿这些终点的下极限至少为 `1/4`。每个固定 `P` 均失败。此例只分离序列性质，**不声称它可由有限支撑蚂蚁实现**。

### 2.2 稀疏黑读缓存失配：可证明接口的充分条件

定义

```text
Recent_s(W,n) :=
  exists j in Nat, j < n and n <= j+W and p_j = p_n.

Miss_s(W,n) := (c_n = true) and not Recent_s(W,n).

E_s(W,N) = #{ n in Nat : W <= n < N and Miss_s(W,n) }.

SparseCacheMisses(s) :=
  exists W in Nat,
    forall k in Nat, k > 0 ->
      exists N0 in Nat, forall N >= N0, k * E_s(W,N) <= N.
```

**候选 C-M（未证明）：**

```text
forall s : State,
  FiniteSupport s.board -> SparseCacheMisses(s).
```

只计“窗口外的黑读”是有意的：窗口未记录的格子默认预测为白。如果很久以前访问过的格子当前为白，默认预测仍然正确，不应算作缓存失配。因此 C-M 比“所有长回访都只有零密度”少一个没有必要的证明义务。

对有限列表形式的初态，`D_s(P,N)` 与 `E_s(W,N)` 都可通过精确有限运行计算。前者需要运行到 `N+P`，后者需要保留最近访问时间和当前颜色。有限统计只能检验给定界，不能认证所有未来极限。

还可精确剥离初始黑格影响。若初始黑格集合为 `B0`，则在任意前缀中，“首次访问且黑读”的次数至多为 `|B0|`：将事件映到该首次访问的初始黑格即可得到单射。因而 C-M 的未知核心仅为**重复访问产生的窗口外黑读**，而非初始黑格的首次接触。这一观察不需要每格暂态，也不需要初始障碍最终全部被访问。

## 3. verify：稀疏失配推出密度周期的完整纸面证明

### 3.1 确定有限自动机

取仓库的 `memoryKey s n W`。它保存朝向及前 `W` 次访问相对当前位置的坐标和这些格子的当前颜色。在 `n>=W` 时，键属于 `memoryKeys W`，其列表长度为

```text
K = 4 * (2 * (2*W+1)^2)^W,     K >= 1.
```

对任意键定义预测颜色：若某条记录的相对坐标为 `(0,0)`，取该条颜色；否则取白。实际键中重复位置的颜色一致，不存在选择歧义。

给定预测颜色 `r` 和朝向 `d`，令 `d'=turn r d`，`u` 为沿 `d'` 的单位位移。下一键按以下确定规则生成：

1. 新朝向是 `d'`。
2. 新近记录为 `(-u, not r)`。
3. 旧记录 `(z,b)` 变为 `(z-u, b xor (z=(0,0)))`。
4. 保留最近 `W` 条；`W=0` 时记录表为空。

对不一致或越界的人工键，将转移规定为某个固定合法键，以得到整个有限键空间上的全函数 `F`。这不影响真实轨道：若 `n>=W` 且 `not Miss_s(W,n)`，预测颜色等于实际读色，真实下一键仍在键空间，且

```text
memoryKey(s,n+1,W) = F(memoryKey(s,n,W)).                 (1)
```

证明分两类：有最近同格记录时使用该记录的当前颜色；无记录时，非失配条件排除黑读，故实际为白。坐标和颜色更新正是 `BoundedMemory.memoryKey_step` 的已有计算，未截断真实棋盘。

### 3.2 有限前缀计数界

令 `Q=K!`。任意有 `K` 个状态的确定全函数，在至多 `K` 步后进入长度不超过 `K` 的循环；所有这些循环长度都整除 `Q`。

若 `n>=W+K` 且闭区间 `[n-K,n+Q]` 内没有失配，则 (1) 在这段轨迹适用。到 `n` 时已经进入该确定轨迹的循环，于是时刻 `n` 与 `n+Q` 的键相同。两端均无失配，所以预测颜色与实际颜色一致，得到 `c_n=c_(n+Q)`。

反之，每个 `n>=W+K` 的滞后 `Q` 失配，都可以归因于 `[n-K,n+Q]` 中的一个缓存失配。每个缓存失配最多影响 `K+Q+1` 个这样的 `n`。因此，对所有 `N : Nat`，

```text
D_s(Q,N)
  <= W+K + (K+Q+1) * E_s(W,N+Q+1).                     (2)
```

端点 `+1` 保证包含 `n+Q` 本身的实际读色失配；不能只检查到 `n+Q-1`。

若 C-M 对状态 `s` 成立，固定平移的 `E_s(W,N+Q+1)` 仍是 `o(N)`，(2) 立即给出 `DensityPeriodicReads s`。用纯自然数量词也可证明：给定 `k>0`，先在 C-M 中取足够大的精度倍数，例如 `4*k*(K+Q+1)`，再使 `N>=Q+1` 且 `N>=2*k*(W+K)`，即可吸收平移和常数项。

**结果：这是一条完成的纸面定理，不是 C-M 的证明。** 它适用于任意初始棋盘。`Q=K!` 极大，只用于数学上固定周期，不建议枚举其全部状态或直接统计该 `Q`。

### 3.3 为什么“异常最终停止”仍等价于原问题

若存在固定 `W,T`，使 `n>=T` 时不再发生缓存失配，则实际键从足够晚开始永久服从确定的 `F`。窗口重复后，读色、朝向和逐步位移永久同步；与 `BoundedMemory.highwayFrom_of_memoryKey_eq` 相同的归纳得到某个 `HighwayFrom`。漂移非零由已有无界性排除零漂移。

反方向，在有限支撑下 `PeriodicTail` 推出 `EventuallyBoundedMemory`，后者当然排除晚期缓存失配。因此

```text
FiniteSupport(s.board) ->
  (PeriodicTail(s) iff
    exists T W, forall n>=T, not Miss_s(W,n)).            (3)
```

这解释了为何必须真正允许**无穷但稀疏**的异常；将“很少”偷偷加强为“有限个”会丢掉弱化的意义。

## 4. refute：真实非周期轨道仍可满足稀疏失配

本节严格使用仓库已实现的无限障碍链，不是 incidence-only 伪路径，也没有在运行中增添障碍。

取 `s*=growingObstacles=scheduledObstacles(fun i => i)`。初始黑格恰为

```text
{ (-68-i*(i+7), -42-i*(i+7)) : i in Nat }.
```

已有 [AperiodicObstacleChain.lean:104](/D:/langtonsant/AperiodicObstacleChain.lean:104) 证明该状态无限支撑、没有任何最终正读色周期，也没有任何最终平移公路。以下只新增它满足弱性质的纸面证明。

### 4.1 直接的密度周期估计

令

```text
T_i = 52*i*(i+7)+132*i = 52*i^2+496*i,
A_i = 12496+T_i.
```

在 `[A_i,A_(i+1))` 中，前 548 位是固定碰撞字，之后 `104*i` 位是标准周期字；这些是 `scheduledObstacles_collision_reads` 和 `scheduledObstacles_standard_reads` 的无限时间接口，不是模拟观察。

对滞后 `P=104`，若 `n` 和 `n+104` 均处于同一标准段，两次读取相同。每个块中其余可能失配的 `n` 至多为 `548+104=652` 个。设 `I(N)=#{i:A_i<N}`，则

```text
D_s*(104,N) <= 12496 + 652*I(N).
```

由于 `A_i>=52*i^2`，`I(N)=O(sqrt(N))`，上述比例趋于零；这对所有大 `N` 成立，不只在块边界成立。故 `DensityPeriodicReads(s*)`，但 `not PeriodicTail(s*)`。

这已经完成全体真实轨道上的严格分离。有限截断最终标准的定理不能把此例变成有限支撑反例，也不能交换“截断长度”和“最终时间”的量词。

### 4.2 更强检查：该轨道也满足稀疏缓存失配

事实上对任意参数序列 `f`，其已认证尾部都可以分为以下宏段：

- 碰撞宏段：长度 548，位置位移 `(-8,-8)`，`weight=x+y` 下降 16。
- 每个追加标准宏段：长度 104，位移 `(-2,-2)`，`weight` 下降 4。

宏段端点及段内位置来自 [VariableObstacleBlock.lean:74](/D:/langtonsant/VariableObstacleBlock.lean:74) 的完整状态匹配，不仅来自读色表。每段长度不超过 548，且每步 `weight` 变化的绝对值为 1。

对 `t>=12496` 设 `H(t)=548*weight(p_t)+t`。在宏段边界，`H` 严格下降：两类段的增量分别为 `548-548*16` 和 `104-548*4`。在任意段内，`H` 相对该段起点的绝对差至多

```text
548*548+548 = 300852.
```

故任意 `12496<=n<=m` 都有

```text
548*weight(p_m) <= 548*weight(p_n) -(m-n) + 602800,
```

因为两端的段内误差之和至多 `601704<=602800=548*1100`。这给出纸面的

```text
BallisticFrom (scheduledObstacles f) 12496 1 1 1 548 1100.
```

常数刻意保守，不声称最优。该推导也说明：没有有限支撑时，即使 `Ballistic` 成立也不推出 `PeriodicTail`；这与仓库等价定理的前提完全一致。

取 `W=602801`。由上式，同一格在两个尾部时刻的访问间隔不超过 602800。再用不需要有限支撑的 `BallisticFrom.avoids_finite`，选择 `U`，使 `n>=U` 时避开 `12496` 之前的有限访问集。于是每次晚期重复访问都能在最近 `W` 步中找到，晚期缓存失配只能来自初始黑格的首次访问。

[VariableFirstVisits.lean:165](/D:/langtonsant/VariableFirstVisits.lean:165) 给出这些首次访问的精确时刻

```text
C_i=12604+T_i=12604+52*i^2+496*i.
```

所以 `E_s*(W,N)<=U+#{i:C_i<N}=O(sqrt(N))`，从而 `SparseCacheMisses(s*)`。同时存在无穷多个失配，因为每个初始障碍都在 `C_i` 首次黑读，之前没有任何同格访问。这同时检验了“密度零并不等于最终为零”。

本节没有宣称在有限支撑域内证明了任何反向不蕴含。

### 4.3 非平凡性的真实动力学负对照：也有不满足密度周期性的轨道

第 2.1 节的二进制序列负对照可进一步换成真实蚂蚁轨道，但仍须使用无限支撑。具体构造参数序列 `f`：第 `r=1,2,...` 轮依次对每个 `k=1,...,r` 添加一批连续相等的参数 `k`。记批次之前已拼接的模块总时间为 `S`，`L_k=548+104*k`，取本批模块数

```text
M = (S+1)^2,
```

随后更新 `S:=S+M*L_k`，并继续下一批。每批长度有限，故这给出明确的总函数 `f : Nat -> Nat` 和已实现的真实初态 `scheduledObstacles f`。

固定任意候选滞后 `P>0`，选 `k` 使 `L_k>P`。之后无穷多轮都有参数 `k` 的批次。该批次内的读色恰为 `spacedColor k` 的完整 `L_k` 周期重复；[SpacedHighwayClassification.lean:65](/D:/langtonsant/SpacedHighwayClassification.lean:65) 证明其任何最终正周期都必须被 `L_k` 整除，故 `P` 不是周期。每个不贴近批次右端的完整模块至少贡献一个滞后 `P` 失配，因而本批贡献至少 `M-1` 个。

在这些批次终点 `N=12496+S+M*L_k` 上，随着轮数增大，`S/M=S/(S+1)^2` 趋于零，故

```text
limsup_N D_(scheduledObstacles f)(P,N)/N >= 1/L_k > 0.
```

这里下标 `N` 只取上述无穷多个终点即可反驳密度零。对每个 `P` 均如此，所以该真实无限支撑轨道不满足 `DensityPeriodicReads`，由第 3 节也不满足 `SparseCacheMisses`。与此同时，第 4.2 节的宏段证明仍给它统一弹道估计。

这排除了“密度周期性也许对所有真实轨道自动成立”的疑虑，并再次展示有限支撑的重要性。构造复用精确无限模块定理，没有把任意二进制字强行当成可实现轨迹；本节为纸面证明，未新建 Lean 检查。

## 5. 真正未完成的步骤，以及如何检验

### 5.1 第一次证明尝试及精确断点

尝试以有限初始黑格作为预算，给所有晚期缓存失配收费。这个归因只对首次黑读有效；重复访问时的黑色可能来自蚂蚁自己很久以前的一次翻色，而非初态黑格。有限支撑不限制运行过程中不断生成的历史棋盘，也不保证一次长回访永久销毁某个资源。

因此失败的具体蕴含是：

```text
初始黑格有限
  -/-> 存在固定 W，使重复访问型 Miss_s(W,n) 的频率趋于零。
```

这里的 `-/->` 表示**本次推理没有证明这一步**，不是宣称已有有限支撑反例。`memoryKey_mem` 的鸽巢原理也不能补足它：重复键遇到未缓存黑格时可以分叉。

### 5.2 下一阶段的最小可检查目标

建议先实现两个小型接口，不先做巨大的周期枚举：

1. `not Miss` 下相同窗口键读色相同，然后复用 `memoryKey_step`。这是 (1) 的局部核心。
2. 对显式有限自动机证明 (2) 的“坏步邻域覆盖”计数引理；用列表过滤和有限循环，不需要分析库。

第一项可先采用如下完整 Lean 证明草稿；**本次没有编译，不能标为内核已核验**：

```lean
import BoundedMemory

namespace LangtonsAnt

def RecentRead (s : State) (W n : Nat) : Prop :=
  exists j, j < n ∧ n <= j + W ∧ (run s j).pos = (run s n).pos

def CacheMiss (s : State) (W n : Nat) : Prop :=
  readColor s n = true ∧ ¬RecentRead s W n

theorem cacheGood_reads_eq {s t : State} {W n m : Nat}
    (hs : ¬CacheMiss s W n) (ht : ¬CacheMiss t W m)
    (hk : memoryKey s n W = memoryKey t m W) :
    readColor s n = readColor t m := by
  by_cases hr : RecentRead s W n
  · exact memoryKey_reads_of_recent hk hr
  · by_cases hu : RecentRead t W m
    · exact (memoryKey_reads_of_recent hk.symm hu).symm
    · have hc : readColor s n = false := by
        cases he : readColor s n with
        | false => rfl
        | true => exact False.elim (hs ⟨he, hr⟩)
      have hd : readColor t m = false := by
        cases he : readColor t m with
        | false => rfl
        | true => exact False.elim (ht ⟨he, hu⟩)
      exact hc.trans hd.symm

end LangtonsAnt
```

数学探索的下一步应只关注 C-M 的新内容：对重复访问型黑读的间隔尾部计数建立**一个固定阈值**的零密度界。允许 `W` 随 `N` 增长会使条件接近平凡，不能替代 C-M。

### 5.3 证明、实验与反驳应分别提交什么

- **证明方向：** 为某类有限初态建立明确的历史资源、充值规则及摊还不等式，导出 `E_s(W,N)<=a_s+b_s*R_s(N)` 且 `R_s(N)=o(N)`。必须证明资源不能通过局部回路无限回收；不能只给“混乱会消散”的解释。对完整有限初态全称命题，本次没有这种资源。
- **有限实验方向：** 记录当前读色、最近同格时间、是否首次访问以及初始颜色；分别统计首次黑读和重复黑读。报告固定 `W` 的 `E_s(W,N)`、分段增量及最大回访间隔，保留完整初态和确切停止条件。多组有限前缀没有发现失配不能证明极限。

## 6. 势函数和时钟路线的精确边界

### 6.1 两类已知否定结论都不是普遍不可能性定理

Jillhewar 的 `rem:nomonotone` 排除的是特定黑格图统计量 `(E,V,k,beta)` 的非常数仿射组合沿全白轨道单调；它不排除空间加权、头部修正、非线性量或返回时刻上的势函数。其单列振荡子还说明局部状态可以恢复，不能无条件把每次局部访问都计为资源耗尽。[固定版本原文](https://github.com/Atharva12456/langtons-ant-highway/blob/76a7e234e577d992d086c204c3dea00ae72cf10a/paper/main.tex)

本仓库 [AxisClockObstruction.lean:21](/D:/langtonsant/AxisClockObstruction.lean:21)、[66](/D:/langtonsant/AxisClockObstruction.lean:66) 的准确前提同时要求 `field` 和 `head` 对水平平移 2 不变。它排除这样的加性整数时钟在全部有限状态、固定轴奇偶扇区内逐步严格增长。不能遗漏 `HeadTwoPeriodic` 后概括为允许任意头部修正；也不能把两条不同初态的四步增量抵消误说成一条真实周期轨道。

### 6.2 全状态严格时钟确实存在

Ke 的固定版本给出如下全状态整数时钟。令 `chi(q)=(-1)^(q.x+q.y)`；垂直朝向时 `sigma=chi(p)`，水平朝向时 `sigma=-chi(p)`，它沿运行不变。固定整数中心 `c`，令 `z(q)=q.x+q.y-c`，`f(z)=3^|z|-1`，`epsilon` 在 N、E 为 1，在 S、W 为 -1，且

```text
J(z,e) = f(z)/2             if e*z >= 0,
         -3*f(z)/2          otherwise;

Theta_c(B,p,h) = -sigma * sum_(q in B) chi(q)*f(z(q))
                + J(z(p),epsilon(h)).

Theta_c(step X)-Theta_c(X)
  = 1+4*f(z(p))*1_{epsilon changes and epsilon(h)*z(p)<0}
  >= 1.
```

求和包含所有黑格，中心在所比较的运行区间内固定。这个例子直接阻止“全状态严格势函数都不存在”的泛化。作者利用局域化时钟给出有限方形区域的统一首次退出界，以及固定高度矩形的退出界；它们不是永久逃离界。[整数时钟及有限域逃逸证明](https://github.com/kehao95/langtons-ant-core/blob/b3429c25c33519c14f58f0a7171a857092bbd4cc/clock_escape/PROOF.md)

### 6.3 同格回访的精确预算，以及缺少什么

以下是由上述恒等式得到的本次纸面推论。任取有限支撑真实轨道、`j<n` 且 `p_j=p_n=p`。本次比较选中心 `c=p.x+p.y`，在整个区间保持不变。两端头部项均为零，即使朝向不同也如此；未改变黑格的贡献抵消。因此

```text
n-j <= Theta_c(X_n)-Theta_c(X_j)
    <= sum_(q in B_j symmetric_difference B_n)
         (3^|q.x+q.y-p.x-p.y|-1).                       (4)
```

式 (4) 保留完整历史；对称差只含这段运行中翻转奇数次的格子。它给出一个合法的回访耗时上界，但右侧随整段远程探索增长，**不是只由端点局部窗口决定的常数**。

若能对所有充分晚的相邻同格访问统一把右侧界为 `C`，就得到统一回访间隔，随后有限初始黑格的首次黑读只剩有限个，进而得到强有界记忆和 `PeriodicTail`。这条强化没有降低原开放块：反过来，周期尾部的统一回访间隔也把 (4) 的右侧界为某个常数，例如每段长度至多 `L` 时可用 `L*(3^L-1)`。所以“证明统一回访时钟预算”本身仍是等价强度路线。

要连接 C-M，较弱但真正新的义务应是：超出某个固定预算的相邻回访，尤其导致黑读的那些回访，只占零密度。时钟单调性没有给出这个分布结论。不能把每个回访预算各自有限，交换为存在一个统一阈值；也不能把离开某个方形的时间有界，交换为今后不再返回。

### 6.4 周期尾预算为什么不能反推周期出现

在已给定非轴周期漂移与完整尾迹时，Ke 的相向指数时钟可在一个完整周期内消去头部项及不变遗迹，得到尾迹相关的周期上界。周期存在、正确的完整平移类及固定尾迹均属于前提。一般暂态没有这种消去；任意轨道的当前有限黑格集大小也不受统一上界控制。故该上界可以有限化给定尾迹的逆向搜索，不能证明未知有限初态最终进入周期，也不能直接界定 C-M 的异常数量。[尾迹预算与非轴周期上界](https://github.com/kehao95/langtons-ant-core/blob/b3429c25c33519c14f58f0a7171a857092bbd4cc/wake_synthesis/PROOF.md)
