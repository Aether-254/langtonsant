# 双前沿探索：首次回访定理与反例

日期：2026-11-22。工作基线为提交 `2a2ccc9`，本轮新增文件尚未提交。

本轮没有启动 Sonnet 或其他多代理工作流，也没有检查或干预 Kaggle、远端 CaDiCaL 作业。结果来自本地推导、有限探索和 Lean 内核验证。一般有限支撑公路猜想及周期轨道分类仍未解决。

## 1. 本次结果的范围

新增的主要正向结果是：**进入新记录前沿的黑读，在该格初始为白的前提下，必定是该格的第二次访问；唯一的先前访问为同位置、同朝向的白读。**

同时得到以下边界：

- 同一前沿的这些支撑区间按时间严格分离。
- 不同前沿的支撑区间可以交错；全白轨迹已有很短的内核认证反例。
- 下一记录对的来源不必是上一记录对的第二个记录格；全白轨迹同样有内核认证反例。
- 两套增长的对角记录前沿、完整 `100001` 局部结构和类内交替读色，单独不足以排除轴向漂移。一个周期 44、完整位移 `(0,4)` 的无限支撑例子已在 Lean 实现。
- 任意横向二周期的加性整数时钟，即使包含位置与朝向修正项，也不能在所有有限棋盘状态上逐步严格增长。

以上最后一项的二周期限制不能省略，44 步例子的无限支撑性质也不能省略。本轮未证明一般漂移为对角方向，更未证明最小周期的完整位移只能为 `(±2,±2)`。

## 2. 正向结果：记录黑读的访问秩恰为 1

令 `p_t`、`d_t`、`c_t` 为实际轨迹在时刻 `t` 的位置、朝向和读取颜色，黑色记为 `true`。取

```text
F(x,y) = s1*x + s2*y,  s1,s2 in {+1,-1}.
```

假设：

1. `m+1` 为严格的新记录，即 `F(p_k)<F(p_(m+1))` 对所有 `k<m+1` 成立。
2. `c_m=true`。
3. 初始棋盘在 `p_m` 为白。

则存在唯一 `j<m` 满足 `p_j=p_m`，并且

```text
d_j = d_m
c_j = false
forall r<m,  p_r=p_m iff r=j
forall k<=m, F(p_k)<=F(p_m).
```

这里的“唯一”量化了此前的全部物理访问，不只是最近一次回访。按从 0 开始的访问秩编号，时刻 `m` 的秩恰为 1。支撑区间 `[j,m]` 因而是同姿态的首次返回，其内部没有再次访问端点格，且整个区间位于旧前沿之后。

### 证明关键

- 每步的 `F` 增量只能为 `±1`。因此 `F(p_(m+1))=F(p_m)+1`，之前所有位置的 `F` 值不超过 `F(p_m)`。
- 对同一个格，朝向的横纵轴由轨迹奇偶不变量固定。任何正时间、位于该旧前沿格的到达都必须沿 `F` 增加的方向，否则其前驱已经越过新前沿。同轴且同为增加方向，强制朝向相同。
- 如果时刻 `m` 之前该格已有一次黑读，同朝向的黑转向会提前进入本应在 `m+1` 才首次到达的新层，矛盾。时刻 0 的特殊情形由初始白色排除。
- 所有先前读取都为白，而每次访问都会翻色，因此先前访问至多一次；当前读取为黑又保证至少一次。

对应 Lean 声明位于 `D:/langtonsant/RecordSupport.lean`：

```lean
record_predecessor_max
record_base_heading
record_base_prior_white
record_black_has_first_return
same_front_sources_ordered
```

定理没有假设全局有限支撑、周期性或弹道性，只要求端点格初始为白。`finiteSupport_white_above` 另证明：对任意有限初态和固定 `F`，存在常数 `B`，使所有 `F(p)>B` 的格子初始为白。因此在足够远的记录前沿，这个局部假设自动满足。

### 同前沿的时间顺序

若 `m<n`，`m+1` 与 `n+1` 是同一 `F` 的记录，且 `p_j=p_n`，则 `m<j`。特别地，若 `[j_m,m]` 与 `[j_n,n]` 都是上述支撑区间，则

```text
j_m < m < j_n < n.
```

证明只使用前沿的严格记录和单位增量。**不同 `F` 之间不能套用此结论。**

## 3. 反例一：不同前沿的区间并不具有层叠性

全白初态实际轨迹中：

| 前沿 | 首次白读 | 第二次黑读 | 新记录时刻 | 端点格 |
| --- | ---: | ---: | ---: | --- |
| `-x+y` | 0 | 4 | 5 | `(0,0)` |
| `x+y` | 1 | 53 | 54 | `(1,0)` |

于是 `0<1<4<53`，两个区间发生真正的时间交错，既不包含也不分离。所有端点、唯一先前访问和记录条件均来自 Lean 认证的实际全白轨迹，不是任意拼接的转向字。

`D:/langtonsant/RecordSupportExamples.lean` 中的 `crossing_distinct_fronts` 正式证明了这件事。它否定任意有限轨迹上的通用层叠性规则；它没有构造白背景周期尾上的双前沿反例。

## 4. 反例二：记录对的来源不必紧邻链接

考虑全白轨迹和 `F=-x+y`。两组相邻记录对为 `(5,6)`、`(79,80)`，而在 `6<n<79` 之间没有新记录。

两次前导黑读及其唯一来源为：

```text
0  -> 4
70 -> 78.
```

如果“下一记录对的来源就是上一对的第二个记录”成立，第二个来源应当为 `4+2=6`。实际是 70；`p_6=(-1,1)`，`p_70=p_78=(1,3)`。前沿在同一最大层上探索了其他格子，才选中新的返回端点。

`source_link_fails` 认证两对记录、间隔内没有记录、两个唯一来源，以及 `70 != 6`。由此不能从有限支撑、初始白色和记录局部结构直接推出来源链接。**仅对白背景周期尾提出的链接猜想仍未被这个暂态反例否定，也没有被本轮证明。**

## 5. 反例三：裸双前沿允许无限背景轴向公路

使用 `1=L=黑`、`0=R=白`，取字

```text
10000100100001011011001101010000100100001010
```

搜索坐标朝东，位移 `(4,0)`；Lean 使用朝北归一化，位移为 `(0,4)`。在 Lean 坐标中，两套前沿为 `-x+y` 与 `x+y`，每周期均增长 4：

| 前沿 | 双向周期延拓中的记录相位 | 记录对起始相位 |
| --- | --- | --- |
| `-x+y` | `[1,2,9,10]` | `[1,9]` |
| `x+y` | `[28,29,36,37]` | `[28,36]` |

记录读取全为 R，每一对都具有完整 `LRRRRL` 局部结构。每个完整平移类按真实稳定时间排序后，颜色交替。但某些类的首次读取为 L。

尤其是四个记录对的前导黑读相位

```text
0, 8, 27, 35
```

全部满足 `priorPhases=[]`。它们没有先前白读供给黑色，依赖初始无限背景。这个位置恰好违反第 2 节的必要条件。

### 无限延续不是只观察几个周期

`D:/langtonsant/PeriodicBackgroundWord.lean` 将已有的白背景实现定理扩展到沿完整漂移不变的背景。各相位的读取条件为

```text
read = background(cell) XOR parity(number of earlier physical visits).
```

经有限的预置前缀后，证明所有未来步骤遵守该字。因此 `D:/langtonsant/DualFrontCountermodel.lean` 已正式证明：

```lean

DualFrontCountermodel.not_finite
DualFrontCountermodel.no_standard_tail
```

它是从某个无限棋盘状态开始永久运行的 44 步平移公路，且不存在任何更晚的 104 步平移公路。没有声称 44 是其最小正周期。

**它不是有限支撑猜想的反例，也没有宣称满足所有已知必要条件。** 它排除的只是“两个记录前沿加局部因子和颜色交替已经足够”的证明捷径。上一份候选中保留“追踪黑读历史来源”的要求仍然必要。

## 6. 标准 104 步字的正向校验

使用仓库 `certifiedColor` 的固定相位和位移 `(-2,-2)`，循环记录相位为 `[22,23,32,33]`。两次前导黑读的完整来源为：

| 黑读相位 | 唯一来源相位 | 来源相对周期 | 实际时间间隔 |
| ---: | ---: | ---: | ---: |
| 21 | 33 | -1 | 92 |
| 31 | 23 | 0 | 8 |

`standard_sources` 在 Lean 中确认 `priorPhases 104 certifiedColor 21=[33]`、`priorPhases 104 certifiedColor 31=[23]` 及相应的位置等式。循环记录列表另外由探索脚本计算；本节不把这份 Python 输出当成新增 Lean 定理。

这里跨周期的来源 33 对应时间 `33-104=-71`，与黑读时间 21 相差 92。不能只按相位大小判断先后。8 和 92 是这类记录支撑的间隔，不是全部格子回访间隔的上界；它们不替代已有的标准公路最大回访间隔 116。

## 7. 一个严格限定的轴向时钟障碍

设整数势函数为

```text
C(s) = sum_{p in black(s)} field(p) + head(pos(s),dir(s)),
```

其中 `field(x+2,y)=field(x,y)`，`head(x+2,y,d)=head(x,y,d)`。对横向、棋盘奇偶或朝向的其他依赖任意，不限于有限个图统计量。

存在两条真实的四步有限轨迹：

```text
E: initial black {(1,-1),(2,-1)}, position (0,0), north
   RRLL -> final black {(1,0),(0,0)}, position (2,0), north

W: initial black {(0,0),(-1,0)}, position (0,0), north
   LLRR -> final black {(-2,-1),(-1,-1)}, position (-2,0), north.
```

对任意上述 `field`、`head`，二者总增量之和等于 0。因此它不可能在每一个有限状态的每一步都严格增长。两个初态均在 `axisParity=0` 的同一扇区，故按该不变量分扇区不能避开反例。

`D:/langtonsant/AxisClockObstruction.lean` 中的 `increment_cancellation` 与 `no_universal_strict_clock` 已证明这两项。

两条轨迹有不同初态，不能拼成一条蚂蚁周期轨道。该结论不排除弱单调时钟、仅在周期尾上成立的时钟、纵向不满足二周期的权重、非线性状态量或含额外历史的返回映射。

## 8. 仍值得保留的数学候选

### 周期尾上的来源链接

一个足以强迫对角漂移的精确候选是：对白背景自洽周期尾，同一增长前沿的每一对记录，其唯一白读来源恰好是上一对的第二个记录时刻。

设第 `k` 对的前导黑读时刻为 `m_k`。该候选写成

```text
j_(k+1) = m_k + 2.
```

记录对的前两步分别沿两个正向坐标轴运动，故

```text
p_(m_k+2) = p_(m_k) + (s1,s2).
```

配合来源位置相等，即可得到 `p_(m_(k+1))=p_(m_k)+(s1,s2)`。若一周期包含 N 对，则 `v=N*(s1,s2)`，所以漂移必须对角。

这是一条条件推导，**未证明来源链接假设**。第 4 节说明它不能由同样的有限暂态局部条件推出；若要证明，必须实质使用无限周期白背景的一致性。标准字满足这个模式，不能据此推广到未知周期字。来源可以跳过哪些边界白读，以及这些跳过量为何不能在周期内形成偏置，是此候选当前的缺口。

### 两套来源匹配，而非两个局部 gadget 的计数

继续研究非对角或轴向漂移时，应保留每个前导 L 的唯一首次 R、完整平移类、跨周期提升量和物理时间顺序。以下两种简化已被排除：

- 把跨前沿支撑区间强行当作不相交或相互包含。
- 删除非记录时刻的边界首次访问，只把上一对记录的第二点当作下一次唯一候选来源。

新的定理给出了可复用的 rank-1 配对对象，但没有给出两套前沿的全局矛盾。它也没有给出回访时长、条带宽度或漂移大小的统一上界。

即使将漂移方向强迫为对角，要将完整位移限制为 `(±2,±2)` 仍必须使用最小正周期，标准字的任意幂会否定没有最小性前提的版本。固定漂移后宽度仍可能未知。非轴固定漂移及固定宽度已有来源中的周期上界，详见先前的来源核验笔记；本轮没有重新形式化该上界。
