# 两个开放块的调研与候选引理（2026-11-21）

## 0. 方法与范围

剩余的两个开放命题（见 `PeriodicWordReduction.lean`、`BallisticGeneral.lean`）是：

1. **弹道性**：每个有限支撑初态都满足 `Ballistic`。由 `BallisticGeneral.lean`，它等价于“每个有限支撑轨道最终出现周期尾部”（`PeriodicTail`）。
2. **自洽字分类**：`ConsistentWordsAreStandard`，即任何白背景自洽周期字都是标准 104 字（的循环移位与重复）。

本轮用多代理工作流调研：18 个子代理（Sonnet），分为文献检索 1 个、仓库梳理 1 个、四个角度各提出至多 3 个候选引理、每个候选配 1 个对抗核验代理。规则：有限模拟不作为无限时间结论的证明；无限支撑的例子不作为有限支撑命题的反例；不假设猜想本身。子代理不修改仓库、不运行 Lean。下文所有“已证明（纸面）”的结论都经核验代理逐步复核，其中前沿记录对与 C4 推论另由主线程独立复核；它们尚未形式化，除第 2 节外都不是 Lean 定理。

## 1. 文献结论

- 唯一已知的一般动力学定理是无界性：对任意初始构形（不限于有限支撑），轨道无界（Bunimovich–Troubetzkoy 1992；文献中也称 Cohen–Kong 定理，归属说法不一）。仓库中的对应结果是 `escapes_finite_set`。推论：无限次访问的格子集合没有“角”。上述陈述在 Gale–Propp–Sutherland–Troubetzkoy（arXiv math/9501233）、Gajardo–Moreira–Goles（arXiv nlin/0306022）、Gajardo–Lutfalla–Rao（arXiv 2409.10124）中读到；原始 1992 论文未读。
- 有限支撑的公路猜想在所读全部文献中都被列为开放问题，没有找到对单黑格、弹道性或其任何弱化形式的证明。
- **白背景公路的唯一性（即 `ConsistentWordsAreStandard`）未在任何所读文献中被处理**，既没有证明也没有反例。不过后续检索发现了 Research Square 预印本 rs-10516269，其标题与这一子问题高度重合，正文尚未读到。此外，单黑格定理已由 Hao Ke 先行发布，带有 Lean 证明。详见 `research/related-work.md`。在核对这两项之前，不能声称本仓库的相应结论是新的。
- arXiv 2409.10124 第 2 节断言“有限构形中的周期轨迹必有白色背景”，并引用 Gajardo 的 *Sofic one head machines*（未读）。这与仓库的 `periodic_tail_consistent_at_start` 相对应，仓库已有完整证明。
- 通用性与公路“种子”的构造（Gajardo–Moreira–Goles）都使用特制的无限背景，不构成有限支撑猜想的反例。

## 2. 已形式化：任意漂移的周期尾部是弹道的

`BallisticGeneral.lean`（纯内核，公理仅 `propext`、`Classical.choice`、`Quot.sound`）：

```lean
theorem HighwayFrom.ballisticFrom_of_pos (h : HighwayFrom s T P v) (hP : 0 < P) :
    BallisticFrom s T (-v.1) (-v.2) (driftNorm v) P (P * driftL1 v + driftNorm v)
theorem ballistic_iff_periodicTail (hs : FiniteSupport s.board) : Ballistic s ↔ PeriodicTail s
theorem ballistic_iff_eventuallyBoundedMemory (hs : FiniteSupport s.board) :
    Ballistic s ↔ EventuallyBoundedMemory s
theorem highwayConjecture_iff_periodicTail_and_consistentWordsAreStandard :
    HighwayConjecture ↔
      (∀ s, FiniteSupport s.board → PeriodicTail s) ∧ ConsistentWordsAreStandard
```

此前仓库只有周期 104、对角漂移的特例 `HighwayFrom.ballisticFrom_of_diagonal`。证明的关键是 `g(t) = P·f(pos t) + |v|²·t` 在尾部是 `P` 周期的，并且每步至多增加 `P·|v|₁ + |v|²`。

**边界**：这只是把第一个开放块改写为更直观的形式，即“每个有限轨道最终沿平移重复”。线性泛函与速度常数被消去，但命题本身没有变弱，仍然开放。

## 3. 经核验存活、尚未形式化的候选

以下记号：`ConsistentWord P w`，漂移 `v = (a,b) ≠ 0`，双向周期延拓后的轨道 `pos`。

### 3.1 前沿记录对（对所有 P 成立；最有结构价值）

取 `f(x,y) = s₁x + s₂y`，其中 `s₁ = sign a`、`s₂ = sign b`（0 时取 1），使 `f(v) = |a| + |b| > 0`。称 `n` 为记录时刻，若 `f(pos n)` 严格大于所有更早时刻的值。

- **C1**：`f(v)` 为偶数；每个整数层恰在一个记录时刻首次到达，且该处读白。记录时刻按相邻对 `(n, n+1)` 出现，每周期 `f(v)/2` 对。
- **C2/C3**：对每个记录对的起点 `n`，有 `w(n-1) = 1`、`w(n) = w(n+1) = w(n+2) = w(n+3) = 0`、`w(n+4) = 1`。也就是说，循环字在每个记录对处都含因子 `100001`，并且 `pos(n+3) = pos(n-1)`、`pos(n+4) = pos(n)`。
- **C4（推论）**：相邻记录对的起点间隔至少为 8，因此 `P ≥ 4(|a| + |b|)`。

证明要点：记录处是首次访问，因此读白右转；第二个记录格之后的格子 `z` 同层且此前未访问；`n-1` 处若读白，则 `n-2` 位于第 `M` 层，与记录条件矛盾。C4 的理由是：`n+4` 处读黑左转，回落到第 `M-1` 层，到达下一对起点所在的第 `M+2` 层至少还需 3 步。

实验（仅作旁证）：在标准公路以及 6 个随机有限初态的公路段上检查了 1648 个记录对，未发现违反。

用途：这是一个对所有周期都成立的局部结构定理，可以直接作为 SAT 编码的剪枝约束，也可能是“由前沿向内逐层确定轨道”这类论证的起点。后一种论证目前没有。

### 3.2 侧向极值层（仅 `a·b ≠ 0`）

取 `g(p) = b·p.1 − a·p.2`，它在整个访问集上有界。`g` 取最大值（或最小值）的格子在整条双向轨道中恰被访问一次，读白；到达与离开方向由 `sign a`、`sign b` 唯一确定。推论：奇数次访问的格子类至少 2 个。轴向漂移（`a·b = 0`）未覆盖。

### 3.3 转向平衡恒等式

记 `L` 为黑读次数，`R = P − L`。则 `R − L` 等于每周期奇数次访问的格子类个数，也就是每周期留下的黑格数，并且 `2L ≤ P`。其余衍生条件（`R − L ≡ 0 (mod 4)`、漂移分量的奇偶）只是“朝向回到北”与移动轴交替的直接改写。

### 3.4 本原字归约

`ConsistentWord (k·p) (w 的 k 次重复) ↔ ConsistentWord p w`。若一个自洽字有循环周期 `q ∣ P`，则长度为 `q` 的片段本身也自洽。因此只需分类本原自洽字。现有定义的比较窗口取 `104·P`，已经能处理重复字；该引理只起到整理作用。

### 3.5 回归格的邻居（任意构形）

若格子 `c` 被无限次访问，则其 4 个邻居中至少 3 个也被无限次访问。这加强了文献中的“无角”引理。推论：无限次访问的格子集合要么为空，要么为无限集。它只是弹道性的必要条件方向上的性质，对两个开放块没有推进。

### 3.6 有限记忆窗口自动机（与周期无关的切片）

设一个自洽字在双向轨道中，同一格子相邻两次访问的时间差都不超过 `W`，则它是一个 `2^W` 状态移位寄存器 `nxtW` 的环，并且环上的净旋转为 0。此归约方向已在纸面证明，需要一个“窗口重新定基是旋转加平移”的框架引理。

穷举实验显示 `nxtW` 的所有环净旋转都不为 0：`W ≤ 23` 经两种独立实现复算，`W = 24, 25` 只有一种实现。因此作为实验结论：**任何周期的自洽字都存在至少 26 步的重访间隔**。标准 104 字的最大重访间隔恰为 116。

若要形式化，需要框架引理，再加上对 `W ≤ 20` 左右的 `native_decide` 不动点检查（像集迭代）。即使做到，它也只排除“记忆短”的字，不能推出分类。

## 4. 被否决或降级的候选

- **条带加有界回退 ⇒ 有限记忆**：证明无误，但其假设在有限支撑下与弹道性等价，属于开放问题的改写。
- **暂态性**（每个格子只被有限次访问）：开放，由猜想推出，也不足以推出任何归约，不宜作为中间目标。
- **最大重访间隔 ≤ 116**：只是 `ConsistentWordsAreStandard` 的必要推论，并且剩余的检查规模为 `2^116`，没有可行的压缩方法。
- **交替字**（只要求同一格子的读数交替、首读不必为白）：确有反例（P = 10，`1111010000`，漂移 (1,1)），但这只说明“白背景”这一条件不可去掉，内容平凡。

## 5. 小结

- 两个开放块都没有被任何候选实质缩小。第一块被重新表述为“每个有限轨道最终沿平移重复”（已形式化）。
- 第二块得到若干对所有周期都成立的必要条件，其中前沿记录对最有结构性。
- 值得继续的方向：
  1. 形式化 3.1，它可以作为 SAT 剪枝约束，也是结构论证的可能起点；
  2. 用 `native_decide` 形式化 3.6 中 `W ≤ 20` 的切片，得到一个与周期无关的排除结论；
  3. 继续推进周期下界的计算（当前为 33，P = 34 与 36 在计算中）。

  这些都不改变两个开放块本身的状态。
